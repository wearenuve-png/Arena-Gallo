# Arena Gallo · Boletos

Demostración de un sitio de boletos para Arena Gallo (Ciudad Cayalá, Guatemala): recorrido en video con el scroll, selector de asientos en 3D, cartelera de eventos y compra simulada.

Sitio de demostración: los eventos, fechas y precios son de ejemplo y ningún pago es real.

```bash
npm install
npm run dev      # http://localhost:5173
BASE=/Arena-Gallo/ npm run build   # compilación para GitHub Pages
```

Hecho con Vite y three.js. Texturas, HDRI y personajes de fuentes CC0 (ver `public/assets/CREDITOS.txt`).
